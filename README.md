# mah-john-blog

麻雀の学びをまとめる公開ブログ。`mah-john` (private) で書き溜めた整形済みの内容を、ここに記事として公開する。

公開URL: https://siotomo.github.io/mah-john-blog/

## 構成

- Jekyll + GitHub Pages（minima テーマ）
- `_posts/YYYY-MM-DD-<slug>.md` に記事を追加して push すると自動公開

## 投稿の追加方法

`mah-john` リポジトリで `publish-blog` スキルを呼び出すと、ここに記事ファイルが追加されて push される。
